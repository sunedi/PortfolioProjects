# 📊 Portfolio Projects

A collection of data science and analytics projects showcasing skills in machine learning, 
natural language processing, big data engineering, statistical analysis, and fraud detection.

---

## 📁 Projects

### 1. 🔤 Natural Language Processing
**File:** `Natural Language Processing Github.ipynb`

An end-to-end NLP pipeline built in Python using Jupyter Notebook. This project explores 
text preprocessing, feature extraction, and model building techniques applied to real-world 
language data.

**Key skills:** Tokenization, text cleaning, vectorization (TF-IDF / word embeddings), 
classification models, Python (NLTK / spaCy / scikit-learn)

---

### 2. ⚡ PySpark SQL Project
**File:** `PySpark_SQL_Project.ipynb`

A big data project leveraging Apache Spark and SQL to process and analyze large-scale datasets. 
Demonstrates distributed computing concepts and SQL querying within a PySpark environment.

**Key skills:** PySpark, Spark DataFrames, SQL queries, data transformation, 
large-scale data processing

---

### 3. 🔍 Credit Card Fraud Detection
**File:** `Report Credit Card Fraud Detection Github.pdf`

A machine learning project focused on detecting fraudulent credit card transactions. 
The report covers the full data science workflow: exploratory data analysis, class imbalance 
handling, model selection, evaluation metrics, and business implications.

**Key skills:** Anomaly detection, classification (Logistic Regression, Random Forest, etc.), 
SMOTE / imbalanced data handling, precision-recall analysis, Python

---

### 4. 📐 Statistical Techniques
**Files:** `Statistical Techniques Github.docx` | `Statistical technique github.Rmd`

A statistical analysis project written in R Markdown, exploring core inferential and 
descriptive statistical methods. Covers hypothesis testing, regression, and data visualization.

**Key skills:** R, R Markdown, hypothesis testing, regression analysis, 
descriptive statistics, data visualization (ggplot2)
